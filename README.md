# 🔐 yap-dm

Encrypted private messages for [**gh-yap**](https://github.com/josemingorance/gh-yap).
*Mensajes privados cifrados de gh-yap. (Español más abajo.)*

Every issue here is a conversation between two people, and every comment is a message encrypted with
[age](https://age-encryption.org) to the SSH keys on their GitHub profiles. **Only they can read the content.**
Who talks to whom, and when, is public. That's the deal.

```sh
gh extension install josemingorance/gh-yap-tui
gh yap dm send @someone "hi"
```

Please don't open issues here by hand: they're ignored. Bugs go to [gh-yap](https://github.com/josemingorance/gh-yap/issues).
